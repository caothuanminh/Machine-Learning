Dự báo giá nhà
Giới thiệu:
Dự án sử dụng thuật toán hồi quy tuyến tính để dự báo giá nhà dựa trên diện tích nhà.
Dữ liệu
File dữ liệu:
"Housing.xlsx"
Dữ liệu gồm 2 thuộc tính chính:
- "area": Diện tích nhà
- "price": Giá nhà
Công nghệ sử dụng
- Python 
- Pandas
- Scikit-learn
- Hồi quy tuyến tính
Cách chạy:
Cài đặt các thư viện:
pip3 install pandas scikit-learn openpyxl
