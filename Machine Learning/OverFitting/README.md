Dự án Machine Learning: Phân tích và Khắc phục Overfitting trong Dự báo Giá nhà
1. Mục tiêu dự án
- Dự án này được thực hiện nhằm minh họa hiện tượng Overfitting (Quá khớp) trong học máy và áp dụng các kỹ thuật (chia tập Train/Test, giới hạn độ phức tạp mô hình, Cross-Validation) để khắc phục, sử dụng bộ dữ liệu dự báo giá nhà.
2. Công nghệ sử dụng
- Ngôn ngữ: Python 3.x
- Thư viện: Pandas, NumPy, Scikit-learn
3. Cấu trúc dự án
├── data/
│   └── train.csv          # Dữ liệu đầu vào
├── src/
│   └── main.py            # Mã nguồn minh họa Overfitting và cách khắc phục
├── requirements.txt       # Danh sách thư viện
└── README.md              # Tài liệu này
